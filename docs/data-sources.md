## 4. 좌표 — API가 아니라 데이터셋으로

**지오코딩 API 응답의 DB 저장은 금지된다. 파일 데이터셋으로 받은 좌표는 저장·재배포가 허용된다.**
같은 위경도라도 취득 경로가 권리를 정한다.

| 소스 | 방식 | 저장 | 조건 |
|---|---|---|---|
| **행안부 도로명주소 위치정보 요약DB** [15050410](https://www.data.go.kr/data/15050410/fileData.do) | 파일 | **가능** | 무료 · **공공저작물 제1유형(출처표시)** · 도로명주소 + 주출입구 X,Y (GRS80 UTM-K) · **juso.go.kr 신청서 + 이용목적 심사 필요** |
| 국토부 지오코더 API [15101106](https://www.data.go.kr/data/15101106/openapi.do) | 실시간 | **불가** | 일 40,000건 · "실시간 사용만 가능" |
| VWorld Geocoder | 실시간 | **불가** | "별도의 저장장치나 데이터베이스에 저장할 수 없습니다" (원문) |
| 카카오 로컬 | 실시간 | **불가** | "응답받은 결과 데이터를 별도로 저장하여 사용하는 것은 허용하지 않으며, 실시간 호출만 가능" |

**채택: 위치정보 요약DB를 내려받아 자체 좌표 테이블로 보유하고 주소를 오프라인 조인한다.**

실시간 API 방식은 산수가 안 맞는다 — 공고 지도 한 장에 마커가 476개면 페이지 1회 열람에 476콜, 일 방문 84명이면 40,000건 쿼터가 소진된다.

## 5. 지도 SDK

**네이버 Web Dynamic Map** 채택.

- 대표계정(Maps를 처음 사용한 계정)에 무료 이용량 제공 — API별 월 3,000 ~ 1억 건
- 지도 로딩 시에만 카운트. 로딩 후 zoom·marker 조작은 미포함
- 거리뷰는 `naver.maps.Panorama` 지원
- **주의:** 이 서비스는 지도가 모든 페이지에 뜨므로 지도 로드 수 = 페이지뷰. 콘솔에서 Web Dynamic Map 실제 한도를 월 페이지뷰 목표와 대조할 것

예비: 카카오맵 JS SDK (지도 30만/일, 단 개발자 계정 첫 활성화 앱에만 · 2026-07-21 정책 변경)
