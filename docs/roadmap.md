# 로드맵

**지역이나 기관으로 좁히지 않는다. 범위를 깊이로 나눈다.**
1층은 API만으로 전국이 완성되고, 2층은 그 위에 호실 단위를 얹는다.
첫 배포부터 전국 서비스가 나오고, 가장 어려운 첨부파일 파싱이 출시를 막지 않는다.

## Phase 0 — 실사·신청 *(현재)*

**목표**: 선행 조건 해소

- [ ] 마이홈포털 3종 API 활용신청 + `붙임1. 요청 파라미터 코드.xlsx` 다운로드 → `docs/api-spec/`
- [ ] 행안부 도로명주소 위치정보 요약DB 신청 접수 (juso.go.kr)
- [ ] 공고문 첨부 재가공·재배포 허용 범위 확인 (LH·SH 이용약관, robots.txt)
- [ ] `zipgonggo.kr` 도메인 가용 확인 후 등록
- [ ] 네이버 Cloud 콘솔에서 Web Dynamic Map 실제 월 무료 한도 확인
- [ ] Neon 프로젝트 생성 + PostGIS 활성화

**완료 기준**: [`data-sources.md`](data-sources.md) "미해결" 6건 전부 확인됨 또는 대안 확정 · 요약DB 신청 접수 완료
**예상**: 2~3일 (승인 대기는 별도)

## Phase 1 — 전국 1층

**목표**: API만으로 되는 것 전부. 첫날부터 전국.

**범위**
- 전국 17개 시도 · LH·SH·GH 전 기관
- 공고 · 단지 · 지역 · 지역×유형 페이지
- 마감 D-day, 발표일, 예비입주자 대기현황, 정정 이력
- **호실 단위 없음**

**산출물**: 수집 스케줄러(S1·S2) · 좌표 조인(S6) · 4개 페이지 템플릿 · 사이트맵 · 지도 컴포넌트

**완료 기준(DoD)**
| 지표 | 기준 |
|---|---|
| 색인 페이지 | 5,000 이상 |
| 좌표 건물 단위 매칭률 | 95% 이상 |
| 공고 게시일 대비 발행 지연 | 24시간 이내 |
| 롱테일 유입 | 발생 확인 |

**예상**: 4~6주

## Phase 2 — 호실 2층

**목표**: 첨부파일 파싱으로 호실 단위 확보

**범위**
- 기관별 파서를 **SH → LH → GH** 순으로 순차 투입
- 전국 커버는 1층에서 이미 확보돼 있으므로 파서 하나가 늦어도 서비스는 돈다
- **민간임대 스크래퍼 병행** (청년안심주택 게시판) — 파서와 독립이라 일정이 얽히지 않는다

> SH부터 시작하는 이유: 호실 단위 데이터가 정형 파일로 공개된 유일한 사례(data.go.kr 15102880)라 파서 출력을 대조해 정확도를 숫자로 잴 수 있다. 정답지가 없는 기관부터 시작하면 무엇이 틀렸는지조차 알 수 없다.

**산출물**: 기관별 파서 3종 · 민간임대 스크래퍼 1종 · 검수 큐 관리 화면 · 호실 상세 템플릿 · 골든 데이터셋 회귀 테스트

**완료 기준(DoD)**
| 지표 | 기준 |
|---|---|
| 파싱 정확도 (SH 공개목록 대조) | 95% 이상 |
| 검수 큐 유입률 | 10% 이하 |
| 색인 페이지 | 30,000 이상 |
| 월 세션 | 5,000 이상 |

**예상**: 6~10주

## 가정과 Plan B

| 가정 | 깨질 경우 |
|---|---|
| 위치정보 요약DB 신청이 승인된다 | **B**: 단지·읍면동 단위 좌표로 먼저 출시, 승인 후 호실 정밀좌표 소급 / **C**: 카카오 유료앱 + 클러스터 방식 지도 |
| 첨부(HWP/PDF)에서 호실 표를 기계적으로 뽑을 수 있다 | **B**: 기관·유형별로 파서를 좁게 만들고 실패분은 검수 큐로 수기 입력. 커버리지가 낮아도 서비스는 성립 / **C**: LLM 보조 추출 + 검수 큐 필수 경유 |
| 마이홈포털 API 운영계정 심의를 통과한다 | **B**: 파일데이터(15088707, 15080989)로 초기 적재, API는 증분 수집만 / **C**: 개발계정 1,000건/일 안에서 시도별 분할 백필 |
| 공고문 재가공물 게시가 약관상 허용된다 | **B**: 원문 첨부는 재배포하지 않고 링크만, 사실 데이터만 재구성 |

## 리스크

- **벤치마크의 실내 사진** — 유튜브 촬영으로 축적된 자산이라 단기간에 따라잡을 수 없다. 사진 대신 데이터 밀도와 최신성으로 경쟁한다
- **자동 생성 페이지의 검색엔진 평가** — 얇은 페이지 규칙을 지키지 않으면 3만 페이지가 통째로 저품질로 묶인다. **색인 페이지 수가 아니라 색인 대비 노출률을 지표로 삼는다**
- **마이홈포털 API 단일 의존** — Phase 1 전체가 여기 얹혀 있다
